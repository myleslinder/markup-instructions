## Where the code doesn't match the plan

1. :checked[The cup is defined as 250 ml, a metric cup, not the US cup that D2 requires]{src="src/convert.js:7"}. This is the cause of I1: `convert(2, "cup", "ml")` gives 500 where the README says 473. The other units (tsp, tbsp, fl oz, pint) are US values, so as it stands a pint isn't two cups. The fix is `cup: 236.588`.
2. :checked[formatAmount rounds to the nearest eighth, but D3 says the nearest quarter]{src="src/scale.js:14-16"}. The comment at the top of the same file cites D3 while the function does something else. :guess[This is probably behind I2]: a 0.3 that is really 0.32 or so rounds to ⅜ in eighths but to ¼ in quarters.
3. :checked[The cups test expects 473, so it should be failing right now]{src="test/convert.test.js:10"}. I worked that out by reading the code, not by running it.
4. :checked[convert rounds to whole units of the target unit, not to whole millilitres as I5 says]{src="src/convert.js:15"}. So it's worse than the issue describes: `convert(100, "ml", "cup")` returns 0. I5's fix should cover every unit, not just spoons.
5. :checked[D2 says metric units convert exactly, but tsp, tbsp and fl oz are cut to 3 decimals]{src="src/convert.js:5-8"}. For example, a US teaspoon is 4.92892 ml and the code uses 4.929. It's a small error, but it goes against the wording of D2.

## Settled

- **D2:** US customary units. The cup doesn't match (see above).
- **D3:** display rounds to the nearest quarter. `formatAmount` doesn't match (see above).
